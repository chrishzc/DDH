# Phase 5 Agent Goal

Harden the confirmed DDH reference runtime so the same Verification Subject has
the same acceptance meaning on supported Windows and Linux environments while
execution, output, process trees, temporary roots, managed assets, capability
fallback, branch-bound architecture queries, and telemetry stay bounded and
non-authoritative.

The release-blocking MVP platforms are vendor-supported Windows 11 x86_64 and
Ubuntu 24.04 LTS x86_64 with Python 3.13 and latest stable. Other platforms are
preview or unsupported exactly as Decision 0022 defines; preview evidence may
never be reported as release-blocking PASS.

Phase 5 package validation has zero external side effects. It does not claim
`work_package_completed`, `subsystem_integrated`, `domain_accepted`,
`release_candidate`, deployment, or release.
