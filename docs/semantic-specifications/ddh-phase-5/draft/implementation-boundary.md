## Before exact confirmation

Only this new Phase 5 specification package may be written. Runtime, tests,
operations, CI, existing Phase 0–4 specifications, decisions, proposals,
System Map assets, Git state, and external systems remain unchanged.

## Future bounded implementation authority

After exact confirmation, Phase 5 may add or extend local DDH contracts,
environment/profile detection, execution planning, bounded subprocess output,
process-tree termination, owned temporary-root handling, Capability Health,
repository-local managed-asset planning/apply, branch-bound Map consumption,

credentials, mutate databases/networks, publish packages, or claim unsupported
platform evidence. CI matrix execution and external runners require separate
authority. Specification-package side-effect budget is zero.
